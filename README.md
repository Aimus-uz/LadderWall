# LadderWall

Плагин для **CounterStrikeSharp** (CS2), который ставит **невидимые твёрдые коробки** в нужных местах карты. Через них нельзя пройти или залезть, поэтому ими закрывают нечестные позиции: лестницы, щели, места для «вахты».

Сделан для сервера **GAMEPOINT.UZ — AWP Lego** (карта `awp_lego_2`).

---

## Как работает

1. В начале каждого раунда, через 1 секунду, плагин смотрит название текущей карты.
2. Если для карты есть координаты, он ставит туда коробку 32×32×32 (модель ящика с de_dust):
   - **твёрдая:** игрок не проходит сквозь неё;
   - **не двигается** (`DisableMotion`);
   - **не ломается:** не получает урон от выстрелов и гранат;
   - **полностью невидимая** (прозрачность 0).
3. CS2 удаляет такие объекты при каждом рестарте раунда, поэтому плагин ставит их заново каждый раунд.
4. На других картах плагин ничего не делает (в логе: `no walls for map '...', skip`).

### Как ищется карта
- Сначала ищется **точное** название (`awp_lego_2`).
- Если его нет, берётся самый длинный ключ из списка, который входит в название карты.
  Например, `awp_lego_2_v2` и `awp_lego_2_cs2` получат стены `awp_lego_2`.

## Требования

- Metamod:Source
- CounterStrikeSharp **1.0.379** (.NET 10)

## Установка

1. Скачай `LadderWall.dll`: вкладка **Actions** → последняя зелёная сборка **Build** → блок **Artifacts** → `LadderWall`.
2. Положи файл на сервер:
   ```
   game/csgo/addons/counterstrikesharp/plugins/LadderWall/LadderWall.dll
   ```
3. Перезапусти сервер или выполни `css_plugins reload LadderWall`.
4. Проверь: `css_plugins list` → в списке есть **LadderWall**.

---

## Команды

Все команды только для `@css/root`.

| Команда | Что делает |
|---|---|
| `!wall` | Ставит **красную** пробную коробку там, где ты стоишь, и пишет координаты в чат: `[wall] X=... Y=... Z=... Yaw=...` |
| `!wallinfo` | Показывает название карты, чьи стены используются (`key`) и их количество (`walls`) |
| `!wallspawn` | Ставит стены прямо сейчас, не дожидаясь нового раунда |

Пробные коробки от `!wall` пропадают в начале следующего раунда.

## Как добавить или поменять стену

1. Зайди на карту, встань в место, которое нужно закрыть, посмотри в нужную сторону.
2. Напиши `!wall`. Появится красная коробка, а в чат придут координаты.
3. Проверь, что коробка закрывает нужное место. Если нет, сдвинься и снова напиши `!wall`.
4. Впиши координаты в `LadderWall.cs`, в блок `_maps`:
   ```csharp
   ["awp_lego_2"] = new()
   {
       (new Vector(1704, 244, 92), new QAngle(0, -85, 0)),
       (new Vector(X, Y, Z), new QAngle(0, YAW, 0)),   // новая коробка
   },
   ```
   Одна коробка закрывает примерно 32×32×32 юнита. Широкие места закрывают 2–3 коробками рядом или одна над другой.
5. Для **новой карты** добавь отдельный блок. Название бери из `!wallinfo` (поле `map='...'`):
   ```csharp
   ["название_карты"] = new()
   {
       (new Vector(X, Y, Z), new QAngle(0, YAW, 0)),
   },
   ```
6. Сделай Commit в `main`: GitHub Actions соберёт новую `LadderWall.dll`.

### Проверка видимости
В `LadderWall.cs`:
```csharp
private const bool Debug = false;   // false: стены невидимые, true: красные (для проверки)
```
Чтобы увидеть, где стоят коробки, поставь `true`, собери и проверь в игре. Потом верни `false`.

## Сборка

Сборка идёт автоматически через GitHub Actions (`.github/workflows/build.yml`) при каждом коммите в `main`. Вручную её можно запустить так: Actions → **Build** → **Run workflow**.

Локально:
```
dotnet publish -c Release -o out
```
Результат: `out/LadderWall.dll`.

### После обновления CounterStrikeSharp на сервере
Поменяй версию в `LadderWall.csproj` на ту, что стоит на сервере:
```xml
<PackageReference Include="CounterStrikeSharp.API" Version="1.0.379">
```
Затем сделай Commit, чтобы собралась новая DLL.

## Возможные проблемы

| Проблема | Что проверить |
|---|---|
| Стен нет | `!wallinfo` → если `walls=0`, название карты не совпадает: добавь блок с этим названием |
| В логе `spawn FAILED` | Модель коробки не загрузилась; проверь, что карта загрузилась полностью, и сделай рестарт |
| Плагин не загружается | Версия CounterStrikeSharp в `LadderWall.csproj` не совпадает с версией на сервере |
| Предупреждение `Unreachable code detected` при сборке | Это нормально: из-за `Debug = false` код внутри `if (Debug)` не выполняется |
